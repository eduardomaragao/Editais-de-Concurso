# Provas anteriores (CURADORIA)

Uma subpasta por concurso de origem, no formato `orgao-uf-ano` (ex.:
`pge-al-2021`). Janela: **2020 em diante**.

Nomenclatura dos arquivos dentro de cada subpasta:

| Tipo | Prova | Arquivo de respostas |
|---|---|---|
| Objetiva | `objetiva-prova.pdf` | `objetiva-gabarito.pdf` |
| Subjetiva | `subjetiva-prova.pdf` | `subjetiva-padrao-resposta.pdf` |
| Oral | `oral-pontos.pdf` (pontos/roteiro) | `oral-espelho.pdf` (critérios) |

Se o concurso tiver mais de uma prova do mesmo tipo (P2 e P3 discursivas),
prefixar: `subjetiva-p2-prova.pdf`, `subjetiva-p3-prova.pdf`.

Regras:
- **Nunca colocar aqui a gravação da prova oral** — divulgação é proibida
  pela banca e elimina o candidato. Só pontos/roteiro e critérios/espelho.
- Guardar a fonte oficial (URL) de cada arquivo no cadastro do app
  (`provas_anteriores[].fonte` no schema) para rastreabilidade.

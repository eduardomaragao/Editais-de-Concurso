Dominador de matérias

A meta de cada matéria sai do tamanho do banco de questões dela, não de um número fixo: 10% do banco com 80% de acerto dá o Domínio; 20% com 85% dá a Excelência; 35% com 90% dá a Cátedra. Se Constitucional tem 800 questões, o Domínio sai com 80 respondidas e pelo menos 64 acertos entre elas. A meta anda sozinha quando você cadastra questões novas.

O acerto é medido numa janela móvel — as últimas meta questões respondidas naquela matéria. É de propósito: quem foi mal no começo não carrega o tropeço para sempre, basta voltar e fazer um novo bloco bem feito. Insígnia de domínio não cai depois de conquistada.

Para juntar no app

O que o app precisa entregar

A regra é a mesma do outro produto: insígnia e ponto são função pura do histórico de respostas — recalculados do zero a cada abertura de tela, nunca acumulados. Assim o placar nunca diverge do estudo real, e mudar uma regra aqui reescreve o passado de todo mundo de forma consistente.

Entrada

  • respondidas, acertos — totais da vida no app
  • maiorMaratona — maior número de questões numa mesma sessão
  • melhorPontaria — maior sequência de acertos sem erro
  • porMateria[id] → totais da matéria + as últimas 300 respostas (a janela móvel do domínio sai daí)
  • banco[id] → quantas questões existem hoje naquela matéria
  • segredos — ids das secretas já disparadas pelo app
  • permanentes — ids já conquistados, que não podem cair

Saída

  • lista de insígnias com conquistada, progresso e pontos
  • as 8 peças da carteira, na ordem
  • total de pontos de ordem
// gamificacao_oab.dart — Dart puro, sem Flutter
final e = EstatisticasOab(
  respondidas: 3120, acertos: 2184,
  maiorMaratona: 112, melhorPontaria: 27,
  porMateria: {
    'constitucional': HistoricoMateria(
      respondidas: 533, acertos: 452,
      recentes: ultimas300De('constitucional'),
    ),
  },
  segredos: {'primario', 'vigilia'},
);

final r = calcularOab(e, banco, permanentes: jaConquistadas);

r.pontos;                          // 50 324
r.conquistadas.length;             // 59 de 146
r.pecasAbertas;                    // 5
r.ultimaPeca?.titulo;              // Número de Inscrição
r.proxima(CategoriaOab.volume);    // Recurso Especial — faltam 80

// insignia de domínio nao cai: guarde o que caiu agora
jaConquistadas.addAll(r.paraGuardar);
